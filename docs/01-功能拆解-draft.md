# 01 · 功能拆解（草稿）

> 状态：draft。待 MVP 范围拍板后升级为 PRD（docs/03）。

## 1. 核心玩法循环（一句话版）

进入关卡 → 做单词任务（选择/拼写/听力/配对）→ 通关拿金币和装备 → 系统按艾宾浩斯安排复习关 → 打 Boss 关 → 解锁新地图 → 循环。

## 2. 功能模块清单

| 模块 | 内容 | 优先级 |
|---|---|---|
| 闯关地图 | 世界/关卡选择，像素风小地图，星级评价 | P0 |
| 玩法题库 | 单词选择、拼写、听音选词、连线配对、句子排序 | P0（先做 3 种） |
| 词库 | 分级词库（按难度/主题分关），含释义、例句、发音 | P0 |
| 角色养成 | 像素小人、金币、经验、装备/皮肤 | P1 |
| 记忆系统 | 艾宾浩斯复习调度（1天/2天/4天/7天/15天）、错题本、生词本 | P0 简版 / P1 完整 |
| AI 口语陪练 | 地图 NPC 触发英语对话，接大模型 API；对话后给简单反馈 | P1（演示版 P0 可模拟） |
| 成就激励 | 每日任务、徽章、连续打卡 | P2 |
| 用户画像 | 进度、正确率、水平评估 → 影响出题难度与 NPC 对话 | P2（文档先讲） |
| 设置 | 音效、语速、难度切换 | P2 |

## 3. MVP 建议（两周内第一版）

**P0（没有它就不算作品）**
- 像素风闯关地图（1 个世界，3-5 关）
- 3 种题型 + 100 词左右词库（分 3 关）
- 金币 / 经验 / 通关星级
- 简版复习提示（答错的词进错题本，下次出现）

**P1（有它才出彩）**
- AI 口语 NPC 1 个：可文字对话，接真实大模型 API
- 艾宾浩斯复习关（到期词自动混入关卡）

**P2（有就加分，没就不做）**
- 成就、排行榜、皮肤、画像驱动的个性化难度

## 4. 技术方向（待拍板）

- **形态**：移动端 H5（手机浏览器 / 可嵌微信），PC 同步兼容
- **游戏引擎候选**：
  - A. **Phaser 3**：成熟的 2D H5 游戏引擎，像素风成熟，学习成本中等
  - B. **轻量 DOM/Canvas**：不用引擎，逻辑简单可控，但动画表现弱
- **AI 对话**：后端转发大模型 API（DeepSeek 等），角色预设（阳光耐心的 NPC），带上下文记忆；也可探索 WorkBuddy 智能体承载
- **发音**：TTS（浏览器 SpeechSynthesis 起步）
- **托管**：GitHub 仓库 + 静态托管，保证「可访问链接」交付

## 6. 风险与对策

- 范围失控 → 只做 P0，功能加进 P1/P2 不进第一版
- 素材不够 → 人物三视图、UI 素材优先用 AI 生成
- AI 对话不稳 → 预设话题引导 + 兜底话术，演示时用固定脚本保底
- 手机体验差 → 从第一天起就在手机尺寸下调试
