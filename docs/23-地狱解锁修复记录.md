# 23 · 地狱解锁修复记录

日期：2026-11-12 凌晨
触发：队长真机截图反馈「东西呢？」——主游戏地图通关三关后看不到地狱模式。

## 现象

主游戏地图（`game.v3.html`）三关状态：遗忘森林 3★ / 回声洞穴 3★ / 静默雪山 2★，
但地图内看不到「地狱模式」入口。

## 根因（两个 bug 叠加）

1. **线上是旧版**：部署的 `game.v3.html` 仍是 pre-hell 快照（79,992B），
   「地图内地狱按钮」从未上线。
2. **解锁读错存档**：地狱按钮和肉鸽 `wqHellUnlocked()` 只读肉鸽存档 `wq_rogue4`，
   而主游戏三关通关写的是 `wordquest.save.v1`，两者不互通 → 即使三关全通也显示 0/3。

## 修复

- `wqHellUnlocked()` 增加 `wqMainClearCount()`：读主游戏三关 `progress[i].stars >= 1`。
  **主游戏三关通关 或 肉鸽三档通关，任一满足即解锁地狱。**
- 主游戏地图地狱按钮改读主游戏三关，文案改为
  「通关 遗忘森林 / 回声洞穴 / 静默雪山 三关后解锁 · 进度 x/3」。

## 改动文件（仓库对照原件零改动）

- `tools/build_lab.py`：UNLOCK_HELPERS、GAME_HELL_JS、GAME_HELL_BTN
- `word-quest-lab/game.v3.html`（81,478B）
- `word-quest-lab/roguelike.v2.html`（123,760B）

## 验证

- node 三场景：三关通 → 已解锁；两关 → 2/3；肉鸽三档通 → 已解锁。
- 重新部署：链接不变，线上 sha256 与本地一致。
