# 《词勇者 Word Quest》投稿作品说明

## 一句话定位

把「背单词」拆成可玩、可死、可复盘的游戏关卡：**用闯关驱动记忆，用 AI 智能体完成内容生产与效果验证。**

## 解决什么问题

传统背词 App 的三个老毛病：
1. **反馈只有对错**，答错了不停留，错过最该记住的那一秒；
2. **没有情绪层**，刷完一页词就关掉，没有继续下去的理由；
3. **效果说不清**，改了玩法到底有没有帮助，靠感觉，不靠对照。

## 作品构成

| 部分 | 内容 |
|---|---|
| 正式版 v1.1 | 100 个四级/六级高频词，3 关线性地图，三种题型，每道题配例句卡，错题本「答对 2 次毕业」，本地真人发音 + 在线 TTS + 设备合成三级回退，声音自检面板 |
| 单词肉鸽 | 四档难度（简单 10 / 普通 25 / 困难 40 / 地狱 60 层）、HP、永久死亡、三选一天赋、分档 Boss、记忆碎片做元货币、应援角色情绪反馈、localStorage 元进度 |
| A/B 方法论 | 平铺对照组 / 词怪战斗 / 单词肉鸽，共用同一套真实词库与四档难度；原始版本全程冻结作对照组，每个迭代版本独立留档 |

## 三个记忆点

1. **背词 × 肉鸽的杂交**——把「错了要付出代价」引入背单词，永久死亡 + 记忆碎片让复习有了沉没成本与继续动机。
2. **例句卡落在答错那一秒**——100 个词全部带英文例句与中文译文，答错时停留、红框高亮、揭示正确答案并展示例句，把最该记住的瞬间做实。
3. **A/B 不是口号，是工程约束**——对照组原件从项目开始到交付零改动，v0 / 对照组 / v2 / v2.1 各自独立留档并打了 Git 里程碑标签，改了什么、为什么改、效果如何都能回溯。

## AI 智能体做了什么

作品围绕「游戏是壳、AI 是核」组织，AI 智能体承担的是**内容生产与验证链路**，而非仅做聊天交互：

- 构建并质检 100 词词库（音标、词性、释义、例句、中译、难度分级、干扰项）
- 批量获取并校验收录 100 个真人发音音频
- 生成题目、干扰项与例句内容，按四档难度组织题库
- 快速产出多个可玩原型（战斗 / 平铺 / 肉鸽），并用无头浏览器自动跑通主循环、验证零报错
- 汇总两方体验反馈，逐条代码取证裁定、排定优先级，形成可追踪的改进闭环

所有产物（词库、文档、版本比对报告、修改跟踪记录）随仓库留档，可复核。

## 技术说明

纯前端单文件应用（HTML + CSS + 原生 JS），无后端依赖；`localStorage` 存档；音频采用「本地 mp3 → 在线 TTS → 设备合成」三级回退，针对移动端浏览器静音策略做了手势解锁；部署为静态站点，手机扫码即可体验。
