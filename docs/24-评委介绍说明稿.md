## 一、30 秒电梯版（时间极紧时用）

各位评委老师好，我们的作品叫《词勇者 Word Quest》，一句话定位八个字——**「游戏是壳、AI 是核」**。

它是一个背单词的像素闯关游戏，但我们真正想展示的不是游戏本身，而是 **AI 智能体如何完成从「内容生产」到「效果验证」的完整闭环**：构建并质检 100 词词库、校验 100 个真人发音、生成题目例句、用无头浏览器自动跑通验证、再汇总两方反馈逐条取证裁定。

同时我们坚持**原版冻结作对照、改动另起文件、打 Git 里程碑标签**，让每一步"改了什么、为什么改、效果如何"都可回溯。

## 三、逐段口播稿

### 环节 1｜开场定位（30 秒）

**投屏**：首页（标题 + 一句话定位）

各位评委老师好，我们的作品叫《词勇者 Word Quest》。一句话概括就是八个字——**「游戏是壳、AI 是核」**。

它是一个背单词的像素闯关游戏，但我们真正想展示的，是 AI 智能体如何完成一个作品从"内容生产"到"效果验证"的完整闭环。

---

### 环节 2｜痛点（30 秒）

**投屏**：停在首页，用「三个老毛病」口播

传统背词 App 有三个老毛病，我们各做一个设计去解决它：

1. **反馈只有对错**——答错了页面一闪就过，错过了最该记住的那一秒；
2. **没有情绪层**——刷完一页词就关掉，没有继续下去的理由；
3. **效果说不清**——改了玩法到底有没有用，靠感觉，不靠对照。

---

### 环节 3｜游戏设计：三关热身 + 地狱主菜（60 秒）

**投屏**：先切正式版答 2 题，再切地狱模式

先看产品主形态。**100 个四级高频词，排成三关线性地图**：遗忘森林、回声洞穴、静默雪山，难度逐关爬坡——从基础高频词一路到 hypothesis、simultaneously 这种难词。

这里有两个记忆点：

**第一，例句卡落在答错那一秒。** 每道题答完都弹出「释义 + 中英例句」，答错时停留、红框高亮、揭示正确答案。把最该记住的瞬间做实，而不是一闪而过。

**第二，错题本"答对 2 次毕业"。** 不是看一眼就完，而是把"连续答对两次"变成毕业条件，逼你真正记下来。

（切地狱）然后是本作品最大的亮点——**背词 × 肉鸽**。通关三关后解锁地狱模式：60 层、每 10 层一个 Boss、永久死亡、三选一天赋、记忆碎片。

为什么这么设计？因为背单词最缺的不是记忆法，是**"错了要付出代价"的沉没成本**。永久死亡 + 记忆碎片，把复习从"机械重复"变成"有压力的闯关"。

---

### 环节 4｜AI 智能体做了什么（60 秒）—— 本作核心

**投屏**：评委版「AI 智能体做了什么」板块

下面是我最想强调的。这个比赛是"AI 智能体创新应用"，评委老师最关心的一定是：**AI 到底干了什么？** 我们的答案是五条：

1. **构建并质检 100 词词库**——音标、词性、释义、例句、中译、难度分级、干扰项，全部校验通过；
2. **批量获取并校验 100 个真人发音**音频；
3. **生成题目、干扰项和例句**，按简单 / 普通 / 困难 / 地狱四档组织题库；
4. **快速产出多个可玩原型**，用无头浏览器自动跑通主循环、验证零报错；
5. **汇总两方体验反馈**，逐条代码取证、裁定真伪、排定优先级，形成可追踪的改进闭环。

一句话：**AI 不是做聊天的，AI 承担的是"内容生产 + 效果验证"的整条链路。** 所有产物随仓库留档，可复核。

---

### 环节 5｜A/B 方法论 + 验证（45 秒）

**投屏**：A/B 版本总览页

最后讲我们的工程约束。

我们不是"想到哪改到哪"。**原版从头到尾冻结作对照组**，每一次改动都另起新文件、打 Git 里程碑标签——v0、对照组、v2、v2.1、正式版 v1.1，都能回溯"改了什么、为什么改、效果如何"。

验证也不是靠感觉。我们用**无头浏览器做真实点击验证**，用音频和网络的埋点去取证。这里我们坚持一个原则——**指标口径先于采集**：先定义清楚"什么叫答对、什么叫毕业、什么叫通关"，再让程序去验证这些口径；样本量不足的地方，我们如实标注"仅供参考"，不把它当成判定依据。

## 四、评委追问 Q&A 预案

**Q1：AI 智能体到底体现在哪？**
A：不是聊天交互，是「内容生产 + 效果验证」链路——词库质检、发音校验、题目例句生成、无头浏览器自动验证、两方反馈逐条取证裁定。所有产物（词库、文档、比对报告、修改跟踪）随仓库留档，可复核。

**Q2：你们有真实用户数据吗？**
A：目前是**过程证据**（自动化验证 + 两轮外部反馈闭环），不是大样本留存数据。样本量不足的部分我们如实标注"仅供参考"，不把它当判定依据——这是我们对待数据可信度的态度，而不是拿虚数充门面。

**Q3：背词×肉鸽，是不是新瓶装旧酒？**
A：肉鸽的"永久死亡 + 沉没成本"机制，正好补上"背词没有情绪层"这个缺口。三关是教学热身、地狱是巩固主菜，中间用"三关全通"当闸门——既避免一进来就劝退，又给了"再来一局"的理由。

**Q4：技术上有什么难点？**
A：移动端浏览器静音策略导致发音失效，我们做了「本地 mp3 → 在线 TTS → 设备合成」三级回退 + 手势解锁；整体是纯前端单文件、零后端依赖，手机扫码即玩。

**Q5：A/B 是认真的吗？**
A：对照组原件从项目开始到交付**零改动**，每个迭代独立留档 + Git tag，可回溯。这是工程纪律，不是口号。

## 五、答辩当天动作清单

1. 手机 / 电脑打开正式版 → **答 2 题**，展示例句卡 + 答错停留；
2. 切评委版 → 点「地狱模式一键直进」，展示 60 层 / Boss / 永久死亡；
3. 切 A/B 版本总览页 → 讲对照组冻结 + 版本标签；
4. 收尾讲「学习动机由玩法承担」；
5. 若评委上手试玩，提前把**手机音量打开**，并提醒可点设置页「声音自检」。
