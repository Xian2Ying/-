# 02 · 待拍板问题清单

> 今明两天和队友过一遍，逐条定结论，把结论写回这份文档（在每题下面加「结论：」）。定完自动升级为 PRD 的输入。

## 1. 游戏名字与世界观

像素闯关需要一个壳（世界观）。候选方向：

- A. **单词冒险岛**：小岛地图，每关一个区域（森林/洞穴/雪山），救 NPC / 找宝箱
- B. **词勇者**：RPG 风，怪物是「单词怪」，打败它 = 学会它，装备驱动
- C. **词境探险（LexiQuest）**：几何/魔幻风，走关卡门解锁新词境

要定：名字、世界观一句话、主角长什么样（参考风格）。

## 2. MVP 范围

建议：P0 = 闯关地图 + 3 种题型 + 100 词 + 金币经验 + 错题本；AI 口语做 1 个 NPC 的演示版（P1）。
要定：同意这个切法？AI 口语是「真实接 API」还是「演示版」先进第一版？

## 3. 技术栈

A. Phaser 3（游戏引擎，表现力强）
B. 轻量 DOM/Canvas（简单可控，开发快）
要定：选哪个？队友 B 的熟悉度优先。

## 4. AI 口语怎么做

- 文字对话起步（输入框），还是直接上语音（录音 + ASR）？
- 建议第一版：文字对话 + 单词点击发音（TTS），语音作为加分项
- 大模型选型：DeepSeek / 其他；是否用 WorkBuddy 智能体承载（交付上更贴大赛要求）
要定：文字 or 语音、模型选型、是否走 WorkBuddy。

## 5. 词库来源与分级

建议：以「高频常用 1000 词」为基础，按难度分 3 档；第一版只做 100 词。
要定：词库哪来（现成开源词表 / 自己整理）、要不要按课本（如四级）？

## 6. 人物与美术

- 主角三视图（站立/行走/施法？）用 AI 生成，像素风
- 需要：主角、3-5 个 NPC、单词怪的样式
要定：风格参考图（发 2-3 张喜欢的像素游戏截图给 AI 当参考）。

## 7. GitHub 仓库

要定：仓库名（建议 `word-quest`）、建在谁的账号下、私有还是公开。

## 8. 移动端验收标准

- 手机浏览器打开即可玩，无需安装
- 竖屏优先，按钮大小适合拇指
- 断网时核心闯关仍可玩（AI 对话除外）
要定：有没有要补充的硬指标（如首屏加载时间）。
