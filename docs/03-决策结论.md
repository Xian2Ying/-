# 03 · 决策结论（基于客观现实的拍板底稿）

> 状态：待队长与队友确认。确认后，结论回填 `docs/02` 每题下方，并升级为 PRD。
> 本文的作用：把「想做什么」和「现实能做什么」对齐，避免第一版做崩。

## 一、客观现实（先算账）

- **时间**：今天 10/30，赛程 11/28 收官 → 29 天（约 4 周）。**报名 11/13 截止（硬节点）**。
- **人力**：3 人，均为在校学生，有课业 / 可能期中 / 有作业。技术担当基本只有队友 B 一人。
- **可投入工时估算**：每人每周 8–12 小时 → 三人合计每周 24–36 小时，4 周约 96–144 小时；扣除磨合、学工具、课业冲突与返工，按 6 折计，有效工时约 **60–90 小时**。
- **必须预留**：调研 + PRD 约 10h；美术素材生成与处理约 8h；测试修 bug 约 15h；PPT + 短视频约 10h。
- **留给核心开发的只有约 20–45 小时**。

**结论**：导师的完整愿景（游戏 + AI 口语 + 记忆系统 + 用户画像 + 两端 + PPT + 视频）在 4 周内**不可能全部实现**。硬上会导致每项都半成品，而评委最看重的是完成度。所以必须砍。

## 二、八项选择（推荐，供拍板）

| # | 决策项 | 推荐结论 | 理由 |
|---|---|---|---|
| 1 | 形态 | **单页 H5，手机竖屏优先**，PC 兼容；不做小程序 | 小程序要注册/审核/资质，4 周风险高；H5 发链接即开，最稳，且便于后续封装 |
| 2 | 玩法 | **关卡地图 + 多样答题玩法**（选择/拼写/听音选词），不做平台跳跃 | 跳跃手感调试极耗时；闯关感靠地图与奖励机制就能拿到 |
| 3 | 技术栈 | **轻量 H5（HTML/CSS/JS），不引引擎** | 只有一个技术担当，引擎学习成本不如花在玩法体验；若 B 有引擎经验再评估 Phaser 3 |
| 4 | AI 口语 | **1 个 NPC：文字对话 + 点击发音（TTS）**，接 DeepSeek API | 语音（ASR）坑多；演示准备固定脚本保底，避免现场翻车 |
| 5 | 词库 | **四级高频前 100 词，分 3 关** | 聚焦大学生，词库自整理，可控 |
| 6 | 记忆系统 | 第一版**简版**：错词进错题本、下次优先出现；完整艾宾浩斯写成"路线图"进 PPT | 保第一版能跑，同时把故事讲大 |
| 7 | 美术 | 先出**主角三视图 + 2 个 NPC**，像素风，AI 生成 | 素材先少后多，够用就够 |
| 8 | 赛道 | 暂归 **AI+教学科研**，群里跟老师确认口径 | 通知与选题页口径不一致，需确认 |

## 四、Fallback 预案

- 队友 B 三天内跑不通游戏框架 → 退到「卡片式闯关」（地图 + 答题，无物理动画），保完整度。
- AI 对话不稳定 → 演示用脚本，但文档/PPT 讲清真实方案。
- 美术来不及 → 先用色块/占位图，保证可玩可演示。
