## 一、产品定位

**名称（工作名）**：词勇者 · Word Quest
> 2026-10-31：队长说「先做吧」，按推荐名 **词勇者** 执行；想改名随时说，改名成本约 5 分钟（改标题 + 世界观文案）。备选：单词冒险岛 / 词境探险。

**一句话**：一款像素闯关风的英语单词游戏——**打怪就是背词，聊天就是练口语**。

**形态**：移动端优先的 H5 单页应用（手机浏览器直接打开，无需安装），PC 端响应式兼容。
**交付物**：一个可访问的链接 + 作品说明 + PPT + 30–60s 宣发视频。

---

## 二、目标用户与使用场景

| 项 | 内容 |
|---|---|
| 核心用户 | 16–24 岁在校学生（高中生 / 大学生），正在准备四级或日常积累 |
| 次要用户 | 6–15 岁少儿（同一套玩法，词库换低龄档）——**只作为「可扩展」写进 PPT，第一版不做** |
| 使用场景 | ① 课间 / 等车 / 睡前 5–10 分钟的碎片时间 ② 宿舍里不想被人听见发音，所以**不做强制跟读** |
| 用户动机 | 「想学但坚持不下去」「不敢开口」 |
| 用户抵触 | 打卡式枯燥、被评分、被提醒「你退步了」 |

**设计推论（三条铁则）**

1. 一局必须能 **3 分钟内**打完（碎片时间容得下）。
2. 全程 **不惩罚**：答错不扣命、不锁关、不显示「你错了 N 次」。
3. 任何需要「持续努力才有效果」的机制（如发音评分），**第一版一律不做**。

## 四、名词定义（团队统一口径）

| 名词 | 定义 |
|---|---|
| 关（Level） | 一个可进入的答题单元，一关 = 10 题 |
| 词库（Deck） | `words.json` 里的全部单词，第一版 100 个 |
| 题（Question） | 一次作答请求，由「词 + 题型」构成 |
| 星（Star） | 关卡评价，0–3 星，按正确率给 |
| 金币（Coin） | 虚拟货币，用于解锁关卡 / 皮肤（第一版只做展示与累计，不做商店） |
| 经验（XP） | 升级用，等级只做展示（Lv.1–Lv.N） |
| 错题本（Mistake Book） | 答错词的集合，下次答题优先复现 |
| 掌握度（Stage） | 单词记忆阶段 0–4，决定下次复习间隔 |
| NPC | 地图上的可交互角色，第一版只有 1 个：口语镇长老 |

## 五、核心玩法循环

```
进入游戏（首页）
   ↓
关卡地图：3 个节点，已通关显示星级，下一关高亮
   ↓
点进关卡 → 10 道题（每答一题：即时对错反馈 + 金币跳动 + 进度条前进）
   ↓
结算页：正确率 / 获得金币 / 用时 / 星级 + 「再来一关」/「回地图」
   ↓
回地图：下一关解锁（或未达 1★ 则本关可重玩）
   ↘
    错题自动进错题本 → 下关掺入复现题
   ↘
    口语镇 NPC 一直可点：文字聊英语，不打分
```

**单局时长**：3–4 分钟（10 题 × 约 15–20 秒）。
**单次会话时长目标**：5–8 分钟（= 打完 1–2 关），不追求长时在线。

## 六、功能需求（P0，逐条可验收）

> 每条含：**做什么 / 规则 / 验收标准**。验收标准必须可数，验收时逐条勾。

### F1 关卡地图（`views/map`）

- 3 个关卡节点纵向排列（移动端）/ 网格平铺（PC 端），节点间用连线连接。
- 节点状态：`已通关`（显示星级，可重玩）/ `可挑战`（高亮发光）/ `未解锁`（锁图标，点击弹提示「先通过第 N 关」）。
- 顶部状态条：等级 / 金币 / 今日连胜（第一版只显示等级与金币）。
- 入口按钮：「错题本」「口语镇」。
- **验收**
  - [ ] 首次进入只有第 1 关可点，第 2、3 关为锁定态且点击有提示
  - [ ] 通关第 1 关后返回地图，第 2 关自动变为可挑战
  - [ ] 已通关节点显示 1–3 颗星，与结算页一致
  - [ ] 手机竖屏下 3 个节点 + 顶部状态条一屏可见，无需滚动

### F2 答题引擎（3 种题型，`core/quiz`）

**单题界面结构（固定，不随题型变）**：顶部进度条 `第 N/10 题` → 题干区 → 选项区 → 底部「跳过/退出」。
**切题动画**：0.2s 淡入，不做复杂转场（省工时）。

| 题型 | 出题方式 | 作答方式 | 判定 |
|---|---|---|---|
| T1 看词选义 | 显示英文单词 + 音标 | 4 个中文释义选 1（点选） | 点选即判，正确项变绿、错误项变红并高亮正确项 |
| T2 听音选词 | 自动播放英文发音（可点喇叭重播） | 4 个英文单词选 1 | 同上 |
| T3 拼写填空 | 显示中文释义 + 首字母 + 下划线格数（如 `a _ _ _ _`） | 屏幕键盘或系统键盘输入 | 点「确认」判；大小写不敏感、忽略首尾空格 |

**出题规则（每关 10 题）**

- 6 题选择题：T1 × 3、T2 × 3
- 3 题拼写：T3 × 3
- 1 题复习题：若错题本非空，从错题里抽 1 个出 T1；否则从本关词池再抽 1 个出 T1
- 干扰项：从**本关词池**抽 3 个其他词，不重复、不与正确答案同义
- 同一关内**不出现重复单词**
- 题序：固定为「T1 T2 T3 T1 T2 T3 T1 T2 T3 + 复习题」，节奏可预期，降低认知负担
- **抽题范围**：本关词池（35/33/32 词）随机抽 10 个，**重玩抽到不同词**，避免「一局只见到 30 个词」
  - 错题本里的词优先被抽中（权重最高）
  - 结算页显示「本关词池 35 词，本局抽到 10 个」——把「词库规模 100」讲清楚，同时给重玩一个理由

- **验收**
  - [ ] 3 种题型都能正常出题、作答、判定
  - [ ] 答对/答错都有明确的视觉 + 音效反馈，反馈在点击后 200ms 内出现
  - [ ] 拼写题大小写、首尾空格不影响判定
  - [ ] 一关内无重复单词，干扰项不重复
  - [ ] 中途退出关卡：进度不保存，但已答题的对错已写入词库掌握度（不丢学习数据）

### F3 词库与内容数据（`src/data/words.json`）

**字段定义（内容官 A 按此填表，我转 JSON）**

```json
{
  "id": "w001",
  "en": "abandon",
  "phonetic": "/əˈbændən/",
  "zh": "vt. 放弃；抛弃",
  "example": "He abandoned his car in the snow.",
  "exampleZh": "他把车丢在了雪地里。",
  "level": 1,
  "pos": "v.",
  "distractors": ["abdicate", "abduct", "absorb"]
}
```

完整文件：`src/data/words.json`（100 条，已通过脚本校验：id 唯一、en 唯一、字段无空、每关词数、干扰项各 3 个、例句含该词）。

| 字段 | 必填 | 规则 |
|---|---|---|
| id | ✅ | `w001` 起顺序编号，不重复 |
| en | ✅ | 全小写，不加空格以外的字符 |
| phonetic | ✅ | 英式或美式任选，**全库统一一种** |
| zh | ✅ | 词性缩写 + 中文释义，多义项用「；」分隔，最多 2 个 |
| example | ✅ | 6–12 词，四级难度以内，必须含该词原形或变形 |
| exampleZh | ✅ | 例句中文对照 |
| level | ✅ | 1 / 2 / 3，对应第 1/2/3 关 |
| pos | ✅ | n. / v. / adj. / adv. / prep. / conj. |
| distractors | ✅ | 3 个**真实存在的英文词**（用于 T2 听音选词的选项），不得是生造词、不得与 `en` 同词根 |

**规模**：100 词，实际分配 **关 1: 35 词 / 关 2: 33 词 / 关 3: 32 词**（以内容官校对台为准，2026-10-31 已交付并转为 `src/data/words.json`）。
**质量底线**：释义与例句 100% 人工校对（内容官签字），不接受 AI 直出未校对。
**干扰项规则**：T2 题的选项 = 该词自带的 3 个 `distractors` + 正确词；T1 题的中文选项 = 从**本关词池**抽 3 个其他词的 `zh`。

- **验收**
  - [ ] `words.json` 100 条，字段齐全，无重复 id / 无重复 en
  - [ ] 3 关词数与上述一致
  - [ ] 每条都有中文例句对照，无空字段
  - [ ] 抽查 10 条，释义与例句无语法/翻译错误

### F4 反馈与奖励（`core/reward`）

| 规则 | 数值 |
|---|---|
| 答对基础金币 | +10 |
| 连击加成 | 连对第 2 题起 +2/题，单题上限 +10（即连对 6 题后每题 +20） |
| 答错 | 金币 +0，**不扣金币、不扣命、不中断关卡** |
| 答对经验 | +5 XP |
| 通关额外经验 | +50 XP |
| 升级 | 每 100 XP 升 1 级 |
| 星级 | 正确率 100% = 3★；≥80% = 2★；≥60% = 1★；<60% = 0★（不通关，可重玩） |
| 通关门槛 | ≥1★ 才解锁下一关 |

- **验收**
  - [ ] 连击数在答题页可见，答错后立即归零
  - [ ] 金币 / 经验在结算页与实际加减一致（手工核对 1 局）
  - [ ] 0★ 时下一关仍锁定，且提示「再来一次，正确率到 60% 就能过关」

### F5 结算页（`views/result`）

- 三块信息：**星级（大图标）→ 三个数字（正确率 / 获得金币 / 用时）→ 一句 NPC 点评**
- 两个按钮：「再来一关」（重玩本关）/「回到地图」（主按钮）
- 底部小字：「本次错了 3 个词，已放进错题本」+ 可点跳转错题本
- NPC 点评按星级给 3 套固定文案（3★ 夸、2★ 鼓励、1★ 更鼓励），**语气必须正向，禁止「你太差了」**
- **验收**
  - [ ] 三个数字与答题过程一致
  - [ ] 两个按钮都能用，返回地图后进度已更新
  - [ ] 星级与 `docs/07` 验收清单一致

### F6 错题本（`views/mistake`）

- 列表：出错的词（英文 + 释义 + 错了几次 + 最近一次时间），按最近出错排序
- 空态：「还没有错题，去闯关吧」
- 两个操作：`单独练这个词`（用 T1 出一题）/ `一键重练全部`（最多 10 个词组成一局）
- 复习成功（连续答对 2 次）后从错题本移除，转入「已掌握」
- **验收**
  - [ ] 答错的词 1 秒内出现在错题本
  - [ ] 「一键重练」能组成一局并正常结算
  - [ ] 连续答对 2 次后该词从列表消失

### F7 进度存档（`core/storage`）

- **唯一入口**：所有读写经 `storage.js`，视图层禁止直接调用 `localStorage`（架构铁律，见 `docs/06`）
- 存档键：`wordquest.save.v1`
- 自动保存时机：每题作答后、关卡结算后、设置变更后
- 首次进入生成默认存档（等级 1、0 金币、全关未解锁）
- 「清空进度」按钮放在设置页，二次确认
- **验收**
  - [ ] 玩到第 2 关后**关闭浏览器再打开**，进度、金币、星级都还在
  - [ ] 断网状态下第 1 关可完整通关（AI NPC 除外）
  - [ ] 设置页「清空进度」后回到初始态

### F8 AI 口语 NPC（P1，演示版，最晚 11-20）

- 入口：地图上的「口语镇」，NPC 立绘 + 对话框气泡（参考星露谷样式）
- 交互：**文字输入** + 快捷话题按钮（「自我介绍」「点餐」「问路」三个场景）
- 能力：接大模型 API（DeepSeek），带 3 轮上下文；回复限 2 句、不超过 25 词
- **零压力规则（硬性）**：NPC 禁止输出「错了 / 不正确 / 应该说」；有语法问题时必须先肯定再用「You could also say…」重述
- 兜底：API 不可用 / 超时 3 秒 → 自动切 **3 段预置对话脚本**，界面无报错
- 点单词发音：气泡内每个英文单词可点，`speechSynthesis` 朗读
- **验收**
  - [ ] 断网时进入 NPC，自动走脚本，无白屏无报错
  - [ ] 连续对话 3 轮上下文不乱
  - [ ] 回复中不含否定性纠错措辞（人工检查 10 条）

### F9 设置与全局（`views/settings`）

- 音效开关、发音语速（0.8 / 1.0）、清空进度
- 全局：所有按钮点击区 ≥ 44×44px；无横向滚动；首屏 3 秒内可交互
- **验收**
  - [ ] 设置在刷新后保持
  - [ ] iPhone Safari + Android Chrome 实测无横向滚动条

## 十二、风险与降级（与 `docs/04` 第八节一致）

1. 做不完 3 关 → 砍到 2 关，前 2 关打磨到位
2. 拼写题问题多 → 砍到 2 种题型（T1 + T2）
3. AI NPC 接不上 → 固定脚本，游戏本体不受影响
4. PC 适配来不及 → 移动端响应式本身就能在 PC 打开，只是不优化

**底线**：一个「打得开、玩得完、讲得清」的 2 关游戏 > 一个什么都有的半成品。
